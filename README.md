# 👾 Pac-Man em Python

Recriação do clássico jogo Pac-Man, desenvolvida em Python como projeto acadêmico.

O projeto busca reproduzir as principais mecânicas do jogo original, incluindo movimentação do personagem, coleta de itens, interação com o cenário e comportamento dos fantasmas.

## 🎮 Funcionalidades

- Movimentação do Pac-Man pelo labirinto.
- Sistema de coleta de pastilhas e pontuação.
- Fantasmas com comportamentos de movimentação.
- Sistema de colisão entre personagens.
- Modo de vulnerabilidade dos fantasmas após consumir uma pastilha especial.
- Condições de vitória e derrota.
- Exibição do cenário e dos elementos do jogo.

## 🛠️ Tecnologias e conceitos

- Python
- Pygame
- WConio2
- Lógica de Programação
- Matrizes e estruturas de dados
- Modularização
- Manipulação de eventos
- Detecção de colisões
- Controle de movimentação

## 📦 Instalação

Certifique-se de ter o Python instalado.

Instale as dependências utilizadas:

```bash
pip install pygame WConio2
```

## 🎯 Objetivo

Aplicar conhecimentos de programação Python no desenvolvimento de um jogo interativo, explorando lógica de movimentação, gerenciamento de estados, interação entre objetos e organização de um projeto de maior complexidade.
